# E-commerce API Automation Testing

## Overview

Java-based API automation framework built using REST Assured,
TestNG and Maven for testing e-commerce APIs.

## Tech Stack

- Java
- REST Assured
- TestNG
- Maven
- JSONPath

## Features

- GET, POST, PUT, PATCH and DELETE
- Bearer token authentication
- Positive and negative API testing
- JSONPath response validation
- Request chaining
- Data-driven testing
- Reusable RequestSpecification
- Configuration management
- Utility classes

## Framework Structure

src/test/java
├── base
├── config
├── data
├── models
├── utils
└── ecommerce

## Test Coverage

- Authentication
- Product APIs
- CRUD operations
- Invalid product scenarios
- Invalid authentication
- Request chaining
